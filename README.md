# Supply Chain Twin D3 Path C Final Project

## Project Summary
This project is a supply-chain disruption response system built as a structured, auditable, and reproducible generative-AI final project.

It includes:
- Path B event-driven closed-loop runtime
- Path C adaptive overlay
- B1-B4 extension branches
- B5 fullstack read-only thesis demo console

## Repository Structure
- `src/` core runtime, Path B, and Path C logic
- `backend/` B5 FastAPI BFF
- `frontend/` B5 frontend
- `bundles/` showcase/demo bundles
- `docs/` boundary, contract, roadmap, and handoff documents
- `tests/` automated test suite
- `scripts/` harness and utility scripts

## Key Deliverables

## Main Project Positioning
This is not a simple generative-AI demo. It is a human-supervised supply-chain decision system with:
- a deterministic truth boundary,
- retrieval-augmented reasoning,
- structured adaptive overlay,
- session comparison and thesis-oriented reporting,
- and a fullstack read-only demo surface.
